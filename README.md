# Adam Web3 - Modern Landing Page

![Vercel Style](https://img.shields.io/badge/Style-Vercel-black?style=flat-square&logo=vercel)
![Status](https://img.shields.io/badge/Status-Live-success?style=flat-square)

Sebuah landing page modern dengan desain minimalis ala **Vercel**, dibangun khusus untuk portofolio dan solusi Web3.

## 🚀 Fitur Utama
- **Modern UI:** Menggunakan sistem desain Vercel yang bersih dan profesional.
- **Geist Typography:** Menggunakan font *Geist Sans* dan *Geist Mono* untuk tampilan yang tajam.
- **Dark Mode Support:** Mendukung tema gelap otomatis berdasarkan preferensi sistem.
- **Vercel Ready:** Sudah dilengkapi dengan konfigurasi `vercel.json` untuk deploy instan.
- **Responsive:** Tampilan optimal di HP, tablet, maupun desktop.

## 🛠️ Teknologi yang Digunakan
- **HTML5 & CSS3** (Custom Variables)
- **Geist Font Family**
- **Git & GitHub**
- **Hermes Agent (Cuki)** - Pembuatan & Pengelolaan otomatis via VPS.

## 📂 Struktur Projek
```text
.
├── index.html     # Halaman utama landing page
├── vercel.json    # Konfigurasi deployment Vercel
└── README.md      # Dokumentasi projek
```

## 💻 Cara Menggunakan
1. Clone repository ini:
   ```bash
   git clone https://github.com/adamsuhelmi13/first_projek.git
   ```
2. Buka `index.html` di browser pilihanmu.

## 🚢 Deployment
Projek ini didesain untuk dideploy dengan sangat mudah ke Vercel. Cukup hubungkan repository GitHub kamu ke dashboard Vercel, dan klik **Deploy**.
